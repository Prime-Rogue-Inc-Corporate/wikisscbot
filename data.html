Check the files

The archive has 82 signed data pulls in its hash chain.

The latest manifest in the chain is 2edf06dd85a103e337860f2a62b92ce27888586565b1b59267cd3a2fa95a7c3a.

git clone https://github.com/Prime-Rogue-Inc-Corporate/wikisscbot
cd wikisscbot
python -m wikisscbot verify          # walks the chain, rechecks every hash
sha256sum -c data/SHA256SUMS         # the same file check with standard tools
pip install opentimestamps-client
ots verify data/manifests/<run>.json.ots   # Bitcoin timestamp

The provenance page lists every run with its hashes and timestamp status, and can walk the chain in your browser. Checksums for every file are in SHA256SUMS, and the run-by-run log is in BUILDLOG.md.
